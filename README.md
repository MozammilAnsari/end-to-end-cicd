# 🚀 Flask Application Deployment with Docker & CI/CD

## 📌 Step 1: Develop and Test Flask Application
Created a Flask application using Python and tested it locally to ensure it runs correctly.

## 📦 Step 2: Manage Dependencies
Collected all required dependencies along with their versions in a `requirements.txt` file.

## 🐳 Step 3: Write Dockerfile
Created a Dockerfile to containerize the Flask application.

## 🔨 Step 4: Build Docker Image
Built the Docker image using the Dockerfile.

## 🧪 Step 5: Test Docker Container Locally
Ran the Docker container locally to verify that the application works inside the container.

## ☁️ Step 6: Push Image to Docker Hub
Pushed the Docker image to Docker Hub for remote access and deployment.

## 🔄 Step 7: Verify Image Pull
Tested pulling the Docker image from Docker Hub to ensure it works correctly.

## ⚙️ Step 8: Automate with Jenkins CI/CD
Installed Jenkins and automated the build, test, and deployment process using a CI/CD pipeline.
